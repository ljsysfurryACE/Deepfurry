WHAT

Deepfurry 是什么

一个从零编译的 Linux 命令行发行版

在 4核 3.8GB 的小 VPS 上
下载 Linux 7.1.5 源码 → 编译内核 → 打包 BusyBox 根文件系统
→ 装 GRUB 引导 → 做成 UEFI 可启动镜像

产物：一个 64MB 的 U 盘镜像，插上就能进 shell

BUILD

编译流程

$ wget linux-7.1.5.tar.xz
$ make defconfig # 794项配置全开
$ make -j4 bzImage # 3.9MB 内核
$ wget busybox # 272命令静态编译
$ mknod initramfs
$ grub-mkimage → BOOTX64.EFI
$ dd if=deepfurry_uefi.img of=/dev/sdX
PITS

编译踩坑

坑1
dpkg 坏了，apt 装不了东西
坑2
kernel.org 下载 15KB/s，拖了3小时
坑3
defconfig 编译要 2-3 小时
坑4
EFI_STUB 编出来的内核没 PE 头
坑5
initramfs shell 脚本找不到 /dev/console
坑6
serial console 不输出，要传 console=ttyS0
坑7
BusyBox kconfig 交互式卡住
坑8
64MB 内存 OOM，改 128MB 才跑起来
